# Developer Adapter Template

هذا المجلد هو الجزء الوحيد الذي يعدل ليتوافق مع أسماء جداول مشروع المبيعات المستهدف.

## قبل التعديل

يقدم المطور Schema الجداول التالية:

- العملاء والموردون والموظفون.
- المخازن والخزائن والمصارف والمصروفات.
- رؤوس وتفاصيل البيع والمرتجع.
- الإيصالات وطرق الدفع.
- المشتريات والمصروفات وحركات المخزون الداخلة في النطاق.

ثم تملأ مصفوفة المواءمة في `../../../Documentation/Accounting_Integration_Field_Dictionary.md`.

## الملفات

- `001_Add_Accounting_Fields.template.sql`: قالب الحقول المباشرة.
- `002_PostSalesDocument_Adapter.template.sql`: مثال Wrapper لفاتورة بيع أو مرتجع.

## تحذير

الملفات ذات الامتداد `.template.sql` ليست ضمن ترتيب التثبيت، ولا تشغل قبل:

1. نسخها إلى ملف باسم خاص بالمشروع.
2. استبدال كل رمز بين `<` و`>`.
3. حذف شرط الحماية في أول الملف.
4. مراجعة المفاتيح وأنواعها.
5. تشغيلها على قاعدة اختبار.
