# قواعد الترحيل في الحزمة المحمولة

## اتفاقية الأعمدة

تحافظ الحزمة على اتفاقية قاعدة CPOS المستخدمة فعليا في قيود البيع والمشتريات والإيصالات:

| المعنى المحاسبي التقليدي | عمود CPOS التقني |
|---|---|
| الطرف المدين | `CREDIT` |
| الطرف الدائن | `DEBIT` |

هذه تسمية تاريخية. لا تبدل الأعمدة داخل Adapter، ولا تعيد تفسيرها في تقرير واحد دون بقية التقارير.

## قيود العمليات

| العملية | `CREDIT` في CPOS | `DEBIT` في CPOS |
|---|---|---|
| بيع | العميل + الخصم المسموح | إيراد المبيعات |
| تكلفة بيع | تكلفة البضاعة | المخزون الخارج |
| مرتجع بيع | مردودات المبيعات + المخزون العائد | العميل + عكس تكلفة البيع |
| شراء دائم | مخزون داخل | المورد + الخصم المكتسب |
| شراء دوري | حساب المشتريات | المورد + الخصم المكتسب |
| مرتجع شراء | المورد | المخزون في النظام الدائم أو مردودات المشتريات في الدوري |
| مصروف | حساب المصروف/المخزون المحمل | الطرف الدائن أو الخزينة |
| قبض | الخزينة + الخصم المسموح | العميل/الطرف |
| صرف | العميل/الطرف | الخزينة + الخصم المكتسب |
| تحويل مخزون | مخزون الوجهة | مخزون المصدر |
| تلف/استهلاك | حساب المصروف | المخزون الخارج |
| زيادة جرد | المخزون | أرباح التسوية |
| عجز جرد | خسائر التسوية | المخزون |

## تصحيحات مقصودة عن الإجراء الحالي

أثناء استخراج `PostAgentBalanceInvoiceToAccounting` ظهرت مشكلتان في فرع تسوية المخزون (`BsType_ID = 39`):

1. قيمة عجز المخزون تجمع `ABS(Bill_T_ID)` بدلا من `ABS(Total)`.
2. اتجاه الزيادة والعجز لا يتسق مع اتفاقية الأعمدة المثبتة في البيع والمصروف والتلف.

لا تنقل الحزمة هذين السلوكين. يستخدم `ACC_PostInventoryAdjustment` قيمة `Amount` الفعلية ويطبق الاتجاه المبين أعلاه.

## نظام المخزون

الحقل `ACC_PORTABLE_SETTINGS.InventoryAccountingMode` يحدد:

- `PERPETUAL`: فاتورة الشراء تدخل حساب المخزون مباشرة.
- `PERIODIC`: فاتورة الشراء تستخدم حساب المشتريات، والمرتجع يستخدم حساب مردودات المشتريات.

القيمة الافتراضية `PERPETUAL` لأنها الأقرب إلى ربط المخازن والتكلفة في CPOS.

## قاعدة التكلفة

كل قيمة مخزون ترسل بقيمة تاريخية مثبتة وقت الحركة. يمنع Adapter من إعادة قراءة التكلفة الحالية للصنف عند إعادة تقييد مستند قديم، لأن ذلك يغير قيد التكلفة من دون تغيير المستند الأصلي.

## الخصومات والضرائب

- خصم البيع يذهب إلى `DISCOUNT_ALLOWED`.
- خصم الشراء يذهب إلى `DISCOUNT_RECEIVED`.
- خصم رأس المرتجع غير مفعل في الإصدار الحالي حتى تعتمد سياسة واضحة لحسابه.
- حسابات VAT موجودة في الحسابات النظامية، لكن توليد أسطر الضرائب سيضاف بعد اعتماد هل أسعار المطور شاملة أو غير شاملة للضريبة.
