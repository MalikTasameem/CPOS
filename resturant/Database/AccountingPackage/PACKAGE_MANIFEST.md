## قاعدة تغيير الحالة

لا تحول حالة أي مكون إلى «مكتمل» إلا بعد:

1. إدراج كل اعتمادياته في الحزمة أو إزالتها بالتصميم.
2. نجاح التثبيت على قاعدة فارغة SQL Server 2014.
3. نجاح إعادة تشغيل ملف التثبيت دون تلف.
4. وجود اختبار نجاح واختبار رفض واحد على الأقل.
5. توثيق مدخلاته ومخرجاته وأكواد أخطائه.
