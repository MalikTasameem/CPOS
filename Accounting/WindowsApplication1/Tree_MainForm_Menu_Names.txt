تقسيم القائمة الرئيسية Tree_MainForm
====================================

1. البيانات الأساسية
--------------------
- الدليل الحسابي
- الأصول الثابتة
- مراكز التكلفة
- العملات
- السنة المالية


2. الإدخال اليومي
-----------------
- القيود اليومية
- سند قبض
- سند صرف
- إدارة الصكوك
- مذكرة التسوية
- استعراض القيود اليومية


3. التقارير المالية
--------------------
- ميزان المراجعة
- ميزان المراجعة - كل الحسابات
- كشف أستاذ
- قائمة الأرصدة
- قائمة الدخل
- قائمة الدخل ربع السنوية
- قائمة المركز المالي
- التدفقات النقدية
- أرصدة مراكز التكلفة


4. الإعدادات والصلاحيات
-----------------------
- إعدادات النظام
- إدارة السندات
- إعداد قوائم الدخل
- إدارة أسعار العملات
- إدارة صلاحيات الحسابات
- المستخدمون


5. الموازنة
-----------
- إدارة الأبواب
- إدارة الفصول
- إدارة البنود
- ربط الحسابات ببنود الموازنة
- اعتمادات الموازنة
- عمليات الموازنة
  - حجز
  - صرف
  - تحويل الحجز إلى صرف
  - تحويل بين بنود الموازنة
- لوحة موقف الموازنة
- تقارير الموازنة
  - الحجوزات


6. الصرافة
----------
- إنشاء عملية صرافة
- إدارة عمليات الصرافة
- سجل مراجعة عمليات الصرافة
- إعدادات الصرافة
  - إعدادات نسب الصرافة
  - إعداد ربط الحسابات


ملاحظات على المسميات
====================

- يفضل استخدام "الموازنة" بدل "الأبواب" لأن القائمة تحتوي على أبواب وفصول وبنود واعتمادات وعمليات وتقارير.
- يفضل استخدام "الإعدادات والصلاحيات" بدل "إدارة النظام" لأنها تشمل المستخدمين والصلاحيات وبعض الإعدادات المالية.
- يفضل استخدام "استعراض القيود اليومية" بدل "قائمة القيود اليومية" لتوضيح أنها شاشة عرض/بحث وليست شاشة إدخال.
- يفضل استخدام "قائمة الدخل ربع السنوية" بدل "قائمة الدخل ربع سنة" لأنها صياغة أوضح.
- يفضل استخدام "الأصول الثابتة" بدل "الأصول الثابته".
- يفضل استخدام "المستخدمون" بدل "المستخدمين" إذا كانت الكلمة عنوانًا مستقلًا.
